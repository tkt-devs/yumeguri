# ADR-010: CSS は CSS Modules ＋ CSS 変数にする

- 状態：決定
- 日付：2026-10-30

## 背景

画面の見た目（CSS）の書き方を決める。CSS のフレームワーク（Tailwind CSS など）を使う方法もよく使われる。

## 選択肢

| 選択肢 | 良いところ | 悪いところ |
| --- | --- | --- |
| CSS Modules ＋ CSS 変数 | CSS そのものを書くので、CSS の基本（レイアウト・Flexbox・Grid）を学べる。Next.js に最初から入っている | 書く量が増える。色や余白の決まりを自分で作る必要がある |
| Tailwind CSS | クラスを並べるだけで、速く見た目を作れる | CSS の基本を学ぶ機会が減る。HTML がクラスの長い列で読みにくくなる |

## 決めたこと

**CSS Modules（`*.module.css`）＋ CSS 変数** にする。色・余白・文字の大きさ・角丸は `styles/` の CSS 変数にまとめ、各コンポーネントは変数を使う。

## 理由

- カリキュラムの HTML・CSS の Day（11〜21）を、このアプリの中で学べる
- 外部のライブラリが要らないので、Next.js の更新で壊れる心配が少ない

## 捨てた選択肢

- **Tailwind CSS**：CSS の基本を学ぶ機会が減るので採らない

## リスクと、その対策

- 色や余白を直書きすると、見た目がばらばらになる。`apps/web/AGENTS.md` で、CSS 変数を使うことを決めている
